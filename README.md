# تطبيق «يمن بزنس» — غلاف البوابة الواحدة (PWA)

يفتح بوابة الدخول الواحدة `/exec?app&w=1` داخل إطار بملء الشاشة، بأيقونة واسم «يمن بزنس» على الجوال.
الملفات: `index.html` (الغلاف)، `manifest.json`، `sw.js` (عامل خدمة يحفظ الغلاف فقط)، `icon-192.png`، `icon-512.png`.
هذا المجلد لا يُرفع إلى Apps Script (`.claspignore` قائمة سماح لملفات الجذر فقط).

## خطوات الرفع إلى GitHub Pages (بعد موافقة المالك — نشر خارجي)
1. مستودع جديد على GitHub (مثلاً `yemen-app`). Pages المجاني يحتاج مستودعاً **عاماً**؛ الملفات لا تحوي أسراراً (رابط /exec فقط، وهو رابط الموظفين أصلاً).
2. ارفع محتوى `app/` إلى جذر المستودع (فرع `main`):
   ```bash
   cd app && git init && git add . && git commit -m "يمن" && git branch -M main && git remote add origin https://github.com/<الحساب>/yemen-app.git && git push -u origin main
   ```
3. في المستودع: Settings ← Pages ← Source: `main` / `(root)` ← Save. الرابط يصير `https://<الحساب>.github.io/yemen-app/`.
4. على الجوال (Chrome أندرويد): افتح الرابط ← ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية» ⇒ أيقونة «يمن بزنس».
5. اختياري: اجعل `ICON_URL` في خصائص السكربت = `https://<الحساب>.github.io/yemen-app/icon-192.png` فتظهر الأيقونة نفسها في كل صفحات /exec.

## إن تغيّر رابط /exec
عدّل `EXEC` في `index.html`، وغيّر `yemen-v3` في `sw.js` (رقم أعلى) ثم ارفع.

## البديل دون استضافة
افتح `/exec` في Chrome ← ⋮ ← «إضافة إلى الشاشة الرئيسية» (الاسم «يمن بزنس» من عنوان البوابة، والأيقونة من `ICON_URL`).
